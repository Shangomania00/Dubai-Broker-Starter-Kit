# Dubai Real Estate Broker Starter Kit

A bilingual Arabic/English interactive static website for a Dubai real estate broker starter kit. Built for SMT Institute × Al Hamoudi Real Estate with a black/gold Dubai luxury UI.

## Files

- `index.html` — main website
- `styles.css` — responsive black/gold UI
- `app.js` — bilingual content, filters, calculator, checklist, quiz
- `assets/` — cleaned transparent logo variants
- `PROMPT.md` — clean master prompt to extend the project

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Save. GitHub will publish the website.

## Accuracy notes

This website is educational and uses public sources for market and fee references. Before using it in a paid training or commercial client presentation, update the data from:

- Dubai Land Department Open Data
- Dubai Land Department Property Sale Registration page
- Dubai Land Department / Dubai Government 2024 and 2025 market announcements
- Dubai REST / Dubai Broker documents for Contract B and Contract F

## Customization

Edit `app.js` for content. Edit `styles.css` for colors and layout. Replace the PNG logos inside `assets/` if you have high-resolution transparent originals.
